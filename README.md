# Steal the Vault Demo

A demo for our CSCI 180 final project on passwords and password managers. 

This project simulates a cloud-based password manager (modeled after LastPass and its 2022 breach) and shows what an attacker can learn/crack from stolen vault data.

**Note**: Everything runs locally and uses only fake users and passwords. No real accounts or services are involved :)
